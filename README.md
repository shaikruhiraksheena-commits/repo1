# Student Grade Tracker

## 📌 Project Description

Student Grade Tracker is a simple Java console-based application developed as part of my CodeAlpha Java Programming Internship.

The program allows the user to enter the details and marks of multiple students. It calculates the total marks, average marks, highest marks, lowest marks, grade, and identifies the topper of the class.

## 🎯 Objectives

- Manage student marks using Java
- Calculate total marks
- Calculate average marks
- Find highest and lowest marks
- Assign grades based on average marks
- Find the topper of the class

## 🛠️ Technologies Used

- Java
- Scanner
- ArrayList
- Classes and Objects
- Loops
- Conditional Statements

## 📚 Subjects

The program accepts marks for:

1. DBMS
2. AI

## ✨ Features

- Accepts the number of students from the user
- Accepts student names
- Accepts marks for three subjects
- Calculates total marks
- Calculates average marks
- Finds the highest marks
- Finds the lowest marks
- Assigns grades
- Finds the class topper

## 📊 Grading System

| Average Marks | Grade |
|---|---|
| 90 and above | A |
| 80 - 89 | B |
| 70 - 79 | C |
| 60 - 69 | D |
| 50 - 59 | E |
| Below 50 | Fail |
